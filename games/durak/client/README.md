# Дурак: клиент

Игровой стол реализован в apps/web/src/components/DurakTable.tsx, изображения карт — PlayingCard.tsx, оформление — durak.css. Используется только тип DurakView из игрового пакета: вычисления правил и PRNG не импортируются во frontend. Подсветка карт, цели защиты и кнопки берутся из server-provided legalActions; сервер повторно проверяет действие. Поддерживаются мышь/тач, выбор нескольких карт для атаки/перевода, SVG-карты, анимации и reduced motion.
