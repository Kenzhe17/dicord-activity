# Правила «Мафии» — r!z3 Arcade

Реализовано в `games/mafia/engine/index.ts` (детерминированный серверный движок, GameModule).

## Участники и роли

- 6–12 реальных игроков, приватные комнаты Activity. ИИ-ботов нет.
- Роли: **мафия** (1 при 6–7 игроках, 2 при 8–10, 3 при 11–12), **комиссар** (1), **доктор** (1), остальные — **мирные жители**. Распределение случайное, из серверного seed; клиент роли не видит.
- Комната вмещает до 12; старт требует минимум 6 готовых участников. Новые игроки в идущую партию не добавляются.

## Цикл партии

`reveal → night → dawn → discussion → voting → (runoff) → night → … → finished`

- **reveal** — карточка своей роли (мафия видит союзников). Длительность по пресету.
- **night** — один серверный этап: мафия голосует за жертву (каждый мафиози — 1 голос, ничья решается ГПСЧ из seed, нет валидных голосов — убийства нет); комиссар проверяет одного живого игрока (не себя); доктор лечит одного живого (может себя, не может лечить одну цель две ночи подряд). Не выбравшие пропускают ход.
- **dawn** — ведущий объявляет результат ночи: имя погибшего или «ночью никто не погиб». Итог проверки комиссара видит только комиссар.
- **discussion** — дневное обсуждение, общий текстовый чат живых.
- **voting** — каждый живой голосует за другого живого или «пропустить»; голос можно менять, считается последний. Кандидат исключается, только если его голоса строго больше числа пропусков. Ничья лидеров → один runoff (30/25/20 c) только между ними; повторная ничья — никто не исключается.
- **runoff** — повторное голосование по тем же правилам, без второго перегона.

## Победа и ничья

- Город побеждает, когда живых мафиози не осталось.
- Мафия побеждает при `мафиози * 2 >= живых всего` (численный паритет).
- Проверка после каждой ночи, исключения и форфейта.
- Три полных цикла без смертей и исключений → ничья.

## Чаты и

- `town` — общий чат живых в дневные фазы; `mafia` — секретный чат живых мафиози только ночью; `dead` — чат выбывших (выбывшие не видят town/mafia).
- Выбывшие наблюдают за партией, не голосуют и не действуют; их роли раскрываются только в конце.
- `feed` — публичные объявления ведущего (ход фаз, жертвы, исключения, победа).
- Лимит сообщения 300 символов, антиспам 1 сообщение/сек на игрока, серверная фильтрация каналов для каждого получателя.

## Статистика матча (видна в конце)

heals, saves (спасённые доктором), checks, checksCorrect (проверки комиссара на мафию), voteKills (голоса за исключённых мафиози).

## Технические решения

- ГПСЧ: mulberry32 от серверного seed, состояние `rng` хранится в checkpoint — реплей журнала детерминирован.
- Таймеры: серверный deadline в состоянии; `getSystemAction` возвращает `advance`/`recover`; фазы восстанавливаются после рестарта (recover даёт +30 c).
- Отключение не убивает персонажа: таймеры идут, действия пропускаются. Форфейт помечает `forfeited` и позволяет выйти из комнаты (совместимо с platform.leave).
- Сериализация: JSON state + zod-схема; `assertInvariants` проверяет состав ролей, длины массивов и консистентность.
