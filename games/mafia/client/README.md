# Мафия: клиент

Игровой стол `MafiaTable` в apps/web получает только персональное представление из `GameModule.getPlayerView`: своя роль и союзники-мафиози, результат проверки комиссара только для комиссара, чаты отфильтрованы по каналам, статистика — только после финала. Полное состояние, чужие роли и скрытые итоги проверок не покидают сервер. Действия идут через версионированный протокол multiplayer (`match:action` / `/matches/:id/actions`); правила в UI не вычисляются.
