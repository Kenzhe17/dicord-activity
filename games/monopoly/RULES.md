# Правила «Монополии» — r!z3 Arcade

Реализовано в `games/monopoly/engine/index.ts` + `engine/board.ts` + `engine/cards.ts`
(детерминированный серверный движок, GameModule). Сервер — единственный источник
правды: кубики, колоды, аукционы и таймеры живут в checkpoint, клиенты получают
только `getPlayerView`.

## Участники и режимы

- 2–6 игроков в приватной/публичной комнате Activity. ИИ-ботов нет.
- **Классика** — каждый сам за себя, до 6 игроков.
- **Быстрая** — те же правила; в форме создания рекомендуется меньше времени на
  ход. Отличие только в подаче/темпе, механика идентична классике.
- **Командная 2×2** — ровно 4 игрока, два банка по 2 человека. У каждого члена
  свой ход и фишка, но деньги и собственность общие на банк. Побеждает последний
  платёжеспособный банк.
- Стартовый капитал, время на ход, время аукциона и сделки — из настроек комнаты
  (по умолчанию 1500 монет, 30/20/120 секунд).

## Доска

Классические 40 клеток: 21 улица в 8 цветных группах, 4 вокзала, 2 коммунальные
услуги, 2 налога, «Шанс», «Сообщество», Тюрьма, «В тюрьму», «Старт»,
«Финальная стоянка». Таблица цен и аренды — `engine/board.ts`.

- **Аренда улиц**: уровень 0 — базовая, далее по таблице; уровень 5 — отель.
  Аренда без домом по цветной группе вдвое ниже, с домами — по таблице.
  Заложенная собственность аренды не даёт.
- **Вокзалы**: 25/50/100/200 по числу своих вокзалов. **Коммунальные**: сумма
  кубиков ×4 (одна своя) или ×10 (обе).
- **Монополия** (все улицы группы): аренда без домов удваивается; с домами
  действует обычная таблица (как в классике Hasbro).
- **Стройка**: равномерно по группе — разница уровней внутри группы ≤ 1
  (`evenBuild`, можно выключить в настройках расширенно; по умолчанию вкл).
  Стоимость дома = `houseCost` клетки, отель = тот же `houseCost` за уровень 5.
  Продажа уровня возвращает половину `houseCost`. Нельзя строить на заложенной
  или незавершённой группе; нельзя заложить улицу с построенными уровнями —
  сначала продать постройки.
- **Залог**: 50% цены; выкуп — 110% залога. Залог можно брать с любой
  незастроенной собственности, в т.ч. во время чужого хода не нужен — только
  владельцу.

## Ход

`awaitRoll → (move/buy/auction/card/debt) → awaitEnd → следующий`

- Кубики серверные (mulberry32 из seed checkpoint). Дубли: +ход; третий дубль
  подряд → немедленно в тюрьму без бонуса.
- Проход «Старта»: +200.
- Покупка: цена с таблички, таймаут → аукцион. Отказ → аукцион сразу.
- **Аукцион**: открытые торги — любой активный банк может поднять ставку или
  пасануть в любой момент; старт 10, шаг +10. Досрочное завершение — когда все,
  кроме лидера, пасанули; иначе — по таймауту. Победитель платит банку. Ставка
  ограничена балансом банка — купить «в минус» нельзя.
- **Тюрьма**: до 3 попыток — дубль выводит и даёт ход; иначе выбор: залог 50,
  карта-выход («пропуск»). После 3-го невезения — принудительный
  выкуп за 50 (или долг, если средств нет). Карта-выход берётся из «Шанса»/«Сообщества», не сгорает при
  получении денег/долге.
- Управление собственностью (`build`, `sell`, `mortgage`, `unmortgage`)
  доступно владельцу в фазах `awaitRoll`/`awaitEnd`; в фазе `debt` разрешены
  только `sell` и `mortgage` (сбор средств). Выкуп из залога в долге недоступен.
- **Долг**: если денег не хватает (аренда, налог, карта, залог), игрок обязан
  продать постройки и/или заложить собственность через действия `sell`,
  `mortgage` в фазе `debt` (таймаут — двойной ходовой). Если нечем платить — банкротство:
  вся собственность и постройки переходят кредитору (или сгорают, если кредитор
  — банк). Банкрот выбывает (`out`), может сдаться кнопкой surrender — эффект тот
  же.
- **Обмен**: `offer` любому активному игроку: деньги и/или собственность уровня 0
  (заложенную можно, с домами — нет) в обе стороны. Стороны видят только свои
  условия; принять может только адресат. Сделка сгорает по таймауту
  (`tradeSeconds`), при банкротстве стороны или если собственность перестала
  быть торгуемой. Во время фазы `debt` обмен тоже доступен — им можно
  рефинансировать долг.
- **Победа**: партия кончается, когда платёжеспособен один банк
  (в командном — один банк из двух). При равном банкротстве в один момент —
  ничья. Результат фиксируется в истории/статистике, рейтинговые очки не меняются.

## Карты

Две колоды по 16 карт («Шанс», «Сообщество»), тасуются из серверного seed,
сброс в колоду при исчерпании. Эффекты: gain/lose/collectEach (по 50/игрока —
«сколько есть у каждого»), moveTo (Start, ближайший вокзал/коммунальная,
тюрьма), moveBack 3, repairs (за каждый уровень построек), gainPerProperty,
getOutCard (пропуск из тюрьмы). collectEach не уводит в минус: каждый
банк платит не больше своего баланса.

## Таймеры и восстановление

- На ход/аукцион/долг действует серверный deadline; пауза (все оффлайн) и
  восстановление после рестарта сохраняют оставшееся время (`pausedRemaining`).
- Системные действия (`timeout`, `pause`, `resume`, `recover`) пишет только
  сервер через `getSystemAction`/`applySystemAction`; клиент подделать их не
  может. Каждое действие — в action log, checkpoint + replay через
  `MatchRuntime`/`restoreMatch`.

## Приватность

`getPlayerView` показывает: состав банков, балансы, позиции, тюрьму, фазы,
торги, входящие/исходящие сделки, свой журнал; колоды отдаются только счётчиками
(`deckCounts`), содержимое колоды и seed клиенту не раскрываются.

## Известные отличия от настольной классики

- Ставки ограничены балансом банка; во время аукциона приём сделок отключён,
  чтобы не увести банк за пределы его текущей ставки.
- «Финальная стоянка» — нейтральная клетка (без сбора банка), сборов нет.
- Банк не «печатает» деньги: долги гасятся только продажей/залогом/обменом.
- Командный режим — проектная надстройка (общий банк двух игроков), в Hasbro
  его нет.
