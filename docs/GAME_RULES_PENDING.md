# Решения перед реализацией движков

В Foundation игровые правила не реализуются. До каждого движка создать RULES.md и согласовать неоднозначные варианты. Значения metadata/настроек сейчас задают границы будущего UI; они не являются молчаливым утверждением спорных правил.

- Дурак: правила согласованы 10 ноября 2026 в [RULES.md](../games/durak/RULES.md). Обратный перевод при двух действующих игроках запрещён, рейтинговые очки не начисляются. Движок и симулятор реализованы на этапе 3.
- UNO-style: состав оригинальной колоды, начальная специальная карта, проверка/оспаривание Wild Draw Four, окно объявления последней карты, правила добора, stack/jump-in (предложены выключенными), подсчёт результатов и исчерпание колоды.
- Мафия: число мафиози по размеру группы, допустимый диапазон игроков (предварительная карточка: 6–16), ограничения лечения себя/повторов, результат проверки комиссара, ночные ничьи, равное голосование, отключения, сроки фаз и управление голосом.

Сначала согласование, затем детерминированный движок, unit/property tests и игровые симуляции. Симуляции 10000 партий для Дурака и UNO не запускались на Foundation: соответствующих движков ещё нет.
