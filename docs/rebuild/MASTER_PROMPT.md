# 10. GAME ENGINE QUALITY

Это критически важный раздел.

Предыдущая реализация имела множество ошибок в игровой логике.

Новая реализация должна использовать:

- Детерминированные state machines.
- Чётко определённые состояния.
- Строгие переходы.
- Server-side validation.
- Immutable state transitions.
- Replayable action logs.
- Game invariants.
- Unit testing.
- Integration testing.
- Property-based testing.
- Automated game simulation.

Игровые движки не должны зависеть от React, Discord SDK или Socket.IO.

Не допускай бесконечных ходов, дублирования карт, незаконных действий, потери состояния и некорректного определения победителей.

Для Дурака и UNO реализуй автоматические симуляции минимум 10 000 партий на каждый поддерживаемый режим, включая разные допустимые количества игроков.

Тесты должны проверять не только отсутствие исключений, но и соблюдение правил.

Все обнаруженные ошибки исправляй на уровне причин.
